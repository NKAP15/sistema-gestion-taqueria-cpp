# sistema-gestion-taqueria-cpp

Sistema de Gestión para Taquería

Sistema desarrollado en C++ para gestionar las operaciones básicas de una taquería, incluyendo inventario, pedidos y clientes.

El proyecto fue desarrollado como parte de mi formación en Ingeniería en Sistemas Computacionales y tiene como objetivo aplicar estructuras de datos, algoritmos de búsqueda y ordenamiento.

Después:

🛠️ Tecnologías

* C++
* Estructuras de datos
* Listas enlazadas
* Árbol binario de búsqueda
* Algoritmos de ordenamiento
* Algoritmos de búsqueda

📌 Funcionalidades

Inventario

* Registrar productos
* Buscar productos
* Mostrar productos
* Ordenar productos
* Eliminar productos
* Control de cantidades

Pedidos

* Registrar pedidos
* Mostrar pedidos
* Eliminar pedidos

Clientes

* Buscar clientes
* Ordenar clientes
* Identificar clientes con mayor compra
